## 🛠 Project Overview
This repository contains Python solutions for the "Principles of Programming 2" course.

- **Practice 1-9**: Core Python concepts, algorithms, and data processing.
- **Practice 10-11**: Graphical applications (Paint, Snake, Racer) using `PyGame` and local `SQLite` databases.
- **TSIS**: Technical Special Internal Studies — focusing on complex database management with `PostgreSQL`.

## ⚙️ Setup & Configuration
For tasks involving databases (Practice 10+ and TSIS):
1. Rename `config.py.example` to `config.py` in the respective directories.
2. Provide your local database credentials in `config.py`.
3. Install requirements: `pip install -r requirements.txt` (if available) or `pip install pygame psycopg2`.
