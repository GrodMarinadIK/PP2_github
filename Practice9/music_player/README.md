# Music Player

A sleek MP3 player with dynamic UI scaling, playlist shuffling, and automated album art discovery.

## Features
- **Dynamic Layout**: Toggle between Windowed and Fullscreen modes with UI adaptation.
- **Smart Artwork**: Automatically loads track icons from the `music_icons` folder.
- **Playlist Management**: Support for skipping tracks and random shuffling.
- **Volume Slider**: Interactive volume control with mouse dragging support.

## File Naming Convention
To ensure the player correctly matches songs with their respective artwork, use the following format for both `.mp3` and `.png` files:
`Author - Song name` (e.g., `Creo - Dimension.mp3` and `Creo - Dimension.png`).

## Controls
- **F**: Toggle Fullscreen mode.
- **P**: Play / Resume.
- **S**: Stop playback.
- **N / Right Arrow**: Next track.
- **B / Left Arrow**: Previous track.
- **R**: Shuffle playlist.
- **Mouse Left Click/Drag**: Adjust volume on the slider.
