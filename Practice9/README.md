# Practice 9: Pygame Collection

A collection of interactive applications built with Python and Pygame for the PP2 course.

## Projects
1. **Mickey's Clock** — Analog clock with Mickey Mouse hands.
2. **Moving Ball** — Interactive game with physics and "Dash" mechanics.
3. **Music Player** — Feature-rich MP3 player with dynamic UI and playlist management.
