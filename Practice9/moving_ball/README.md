# Moving Ball Game

A simple interactive game featuring a red ball with "Geometry Dash" style aesthetics and smooth physics.

## Features
- **Smooth Movement**: High-precision float-based coordinates.
- **Boundary Clamping**: The ball stays perfectly within the screen limits.
- **Sprint Mechanic**: Hold `Space` to move faster (Dash mode).
- **Custom Visuals**: Styled with a distinctive outline and core.

## Controls
- **WASD / Arrow Keys**: Move the ball.
- **Space Bar (Hold)**: Sprint / Dash mode.
- **Close Window**: Exit the game.
