## 📝 Assignments Overview

### 📞 1. Extended PhoneBook
An advanced contact management system.
- **Key Features**: Relational database design, multi-field search, and data migration scripts.
- **Tech**: `psycopg2`, `PostgreSQL`.

### 🎨 2. PyPaint
A custom drawing tool with geometric shape support.
- **Key Features**: Flood fill, Undo system, and custom shape algorithms (Rhombus, Triangles).
- **Tech**: `pygame`, `math`.

### 🏎 3. Racer
High-speed arcade racing.
- **Key Features**: Dynamic difficulty scaling, randomized enemy spawning, and coin collection mechanics.
- **Tech**: `pygame`.

### 🐍 4. Snake: Database Edition
Classic Snake game with a persistent scoring system.
- **Key Features**: Levels, adjustable speed, and a leaderboard saved in a database.
- **Tech**: `pygame`, `PostgreSQL`.

## 🛠 Prerequisites

To run these projects, you will need:
1. **Python 3.10+**
2. **Pygame**: `pip install pygame`
3. **Psycopg2**: `pip install psycopg2`
4. **PostgreSQL**: A running instance for TSIS 1 and TSIS 2.
